# Bagl brand files

The logo is a bagel with a bite taken out at the upper right, next to the word "bagl" drawn as custom outlined letters. Five tapered sesame seeds follow the ring of the bagel. `bagl-design-system.png` shows the whole guide on one page.

## Files

| File | Use |
| --- | --- |
| `bagl-logo.svg` | The horizontal logo, with a Toast bagel and an Ink wordmark, for light backgrounds. |
| `bagl-logo-ink.svg` | The horizontal logo in Ink only. |
| `bagl-logo-cream.svg` | The horizontal logo in Cream only, for dark backgrounds. |
| `bagl-logo-ribbon.svg` | The Cream logo centered on an Ink band. |
| `bagl-symbol.svg`, `bagl-symbol-ink.svg`, `bagl-symbol-cream.svg` | The bagel alone, in Toast, Ink and Cream. |
| `bagl-symbol-small.svg` | The bagel without seeds, for 16 to 24 px. |
| `bagl-wordmark.svg` | The word alone. |
| `tokens.css` | The interface colors, type, spacing and corner radius. |

The Illustrator sources are not in the repository.

## Rules

- Leave clear space of at least a quarter of the symbol's width around the logo.
- Don't show the symbol smaller than 32 px, or the horizontal logo narrower than 140 px. Below 32 px, use the seedless symbol, which works from 16 to 24 px.
- Keep the bite at the upper right, and keep the proportions.
- Use the Cream logo on dark surfaces.

## Colors and type

| Name | Hex | Use |
| --- | --- | --- |
| Ink | `#282420` | Text, and dark backgrounds |
| Toast | `#D9793B` | Accents. It is too light for text on Cream, so use it as a fill with Ink text. |
| Cream | `#FFF8ED` | Light backgrounds, and text on Ink |
| Crust | `#8B4A2B` | Secondary text and links on Cream |

The interface uses Avenir Next, in Demi Bold for headings and Regular for text, and code uses Menlo Regular. The fonts are not included, and the logos don't need them because their letters are outlines.
